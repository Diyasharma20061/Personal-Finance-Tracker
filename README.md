# 💰 Personal Finance Tracker

A modern and responsive web application that helps users manage their personal finances, track income and expenses, and monitor their budget.

## ✨ Features

- 💰 Track total income
- 💸 Track total expenses
- 📊 View financial summary
- ➕ Add income and expense transactions
- 🗑️ Delete transactions
- 📈 Visual financial chart
- 💵 Budget tracking
- 💾 LocalStorage data persistence
- 📱 Responsive design
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- LocalStorage

## 🚀 How to Use

1. Open the Personal Finance Tracker.
2. Enter your income or expense details.
3. Add the transaction.
4. View your updated financial summary.
5. Track your budget and expenses using the dashboard.
6. Delete transactions whenever required.

## 🎯 Project Purpose

This project was developed to practice frontend web development and create a practical personal finance management application.
